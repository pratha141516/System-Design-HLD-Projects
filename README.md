# System Design – High-Level Design (HLD) Projects

A collection of three **High-Level Design (HLD)** case studies prepared as part of B.Tech CSE, 5th Semester coursework for **System Design (TCS-504)**.

## Projects

### 1. Food Delivery System
A high-level design for a food delivery application similar to Swiggy or Zomato.

- User registration and authentication
- Restaurant and menu browsing
- Cart and order management
- Online payment flow
- Delivery assignment and order tracking
- Suggested database schema and design considerations

[View Food Delivery System HLD](Q1_Food_Delivery_System_HLD.pdf)

### 2. Notification System
A high-level design for a notification platform supporting multiple delivery channels.

- User notification preferences
- Email, SMS and push notifications
- Notification templates and history
- Delivery status tracking
- Retry handling for temporary failures
- Suggested database schema and reliability considerations

[View Notification System HLD](Q2_Notification_System_HLD.pdf)

### 3. URL Shortener
A high-level design for a URL-shortening service similar to Bitly.

- Long URL validation
- Unique short-code generation
- Short URL redirection
- Short-code to long-URL mapping
- Click tracking and analytics
- Cache and database considerations

[View URL Shortener HLD](Q3_URL_Shortener_HLD.pdf)
